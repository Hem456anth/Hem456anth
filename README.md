## 🚀 About me

I'm **Hemanth Kundrapu**, a student builder who turns ideas into **installable apps** — Android, Windows and AI tools — and ships them with CI, releases and honest docs.

- 🛠️ Right now: **Orange** (drag-and-drop file converter for Windows) and **Bharat Map** (India-first maps)
- 🔍 I study how great apps work (clean-room, behaviour only) and rebuild them open-source
- 🤖 AI agents & automations with Gemini, Sarvam, n8n and CrewAI
- 🎓 Placement prep: Java, DSA, SAP
- 💬 Ask me about: Kotlin/Compose, WinUI 3, FastAPI, GitHub Actions release pipelines
